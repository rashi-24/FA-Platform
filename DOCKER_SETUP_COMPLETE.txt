================================================================================
                        ⚠️ IMPORTANT NOTES
================================================================================

1. SECURITY:
   - Change SECRET_KEY before first run
   - Change POSTGRES_PASSWORD before first run
   - Set DEBUG=False for production
   - Configure ALLOWED_ORIGINS for production

2. PORTS:
   - 3000: Frontend (configurable via FRONTEND_PORT)
   - 8000: Backend API (configurable via BACKEND_PORT)
   - 5432: PostgreSQL (configurable via POSTGRES_PORT)

3. DATA PERSISTENCE:
   - Database data is stored in Docker volume: fa-platform-postgres-data
   - Survives container restarts
   - To delete: docker-compose down -v

4. FIRST RUN:
   - Database auto-initializes on first start
   - Demo data auto-seeds if SEED_DEMO_DATA=true
   - May take 30-60 seconds for full startup

================================================================================
                        🆘 TROUBLESHOOTING
================================================================================

Problem: Port already in use
Solution: Change port in .env (BACKEND_PORT=8001, FRONTEND_PORT=3001)

Problem: Database won't start
Solution: docker-compose logs db (check logs)

Problem: Backend can't connect to database
Solution: docker-compose restart db && docker-compose restart backend

Problem: Permission denied on entrypoint script
Solution: chmod +x backend/docker-entrypoint.sh && docker-compose up -d --build

For more help, see: DOCKER.md
